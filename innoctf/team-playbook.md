## ⚔️ 10:40–13:00 и 14:00–17:00 · БОЙ — петля на каждый раунд (2 мин)
```
┌─ каждые 2 минуты (один раунд) ──────────────────────────────┐
│ 🚒 инфра   → глянул healthcheck (всё ✅?) + табло (нет MUMBLE/CORRUPT?) │
│ 🛡️ защита  → смотрит трафик в Packmate: кто и чем бьёт наш сервис      │
│ ⚔️ атака   → льют флаги через ферму; ферма сама шлёт жюри и ретраит    │
│ 🎖️ капитан → держит табло, раздаёт приоритеты: что чиним первым        │
└──────────────────────────────────────────────────────────────┘
```

**Когда что-то случилось (роль инфра/защита):**
| Сигнал | Кто ловит | Что делаем |
|---|---|---|
| 🔔 сервис DOWN (сторож орёт) | 🚒 инфра | `restore.sh` из последнего orig-сейва ИЛИ `docker compose up -d`. НЕ пересоздавать с нуля |
| 🩹 защитник нашёл дыру | 🛡️→🚒 | защита пишет патч → инфра катит `redeploy.sh <папка> <метка>` → ждём 1 раунд → табло |
| 🟡 MUMBLE / CORRUPT на табло | 🎖️→🚒 | капитан увидел на табло → инфра откатывает патч; **базу не трогаем** |
| 📋 нужны логи сервиса | 🛡️ | `collect-logs.sh <папка>` → файл защитнику |

🧠 Главное правило инфры: **сначала сейв, потом патч.** Откат данных = CORRUPT = теряем старые флаги.
