# 💾 Политика бэкапов — команда, читаем все!

## Картинка-запоминалка 🎮
Бэкап = **сейв перед боссом**. Патч = босс. Проиграл → загрузился → цел.

## Правила
1. **В первые 5 минут игры** — бэкап ВСЕХ сервисов как выдали (`./backup.sh <папка> original`).
   Ещё лучше: `scp -r` оригиналы к себе на ноут — вдруг сервер умрёт.
2. **Перед КАЖДЫМ патчем** — `./backup.sh <папка> <что-чиним>`. Без бэкапа патч не катим.
3. **После патча** — смотрим healthcheck + вердикт чекера 1–2 раунда.
   Стало DOWN/MUMBLE → `./restore.sh <последний.tgz> <папка>` сразу, без споров.
4. **Бэкапим КОД, не ДАННЫЕ.** Откатить БД = потерять флаги, положенные после → CORRUPT 🧥❌.
5. Имя архива = что чинили (`notes-213501-token-fix.tgz`) → откат за 10 секунд.
6. Кто патчит — пишет в чат команды: «патчу notes, бэкап есть». Двое в одном сервисе = беда.

## Альтернатива-лайт: git
В папке сервиса: `git init && git add -A && git commit -m original`,
дальше перед патчем `git commit -am "до фикса"`, откат `git checkout .` → `docker compose up -d --build`.
