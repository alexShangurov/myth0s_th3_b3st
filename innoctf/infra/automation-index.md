# 🤖 Индекс автоматизации инфры (INNOCTF, 21.11)

Всё — **защита и инфра** (твоя роль). Атакующих скриптов тут нет.
Правило дня: **автомат делает рутину, решение «откатывать / трогать базу» — всегда ты.**

## Ситуация → скрипт → что остаётся руками

| Скрипт | Когда запускать | Что делает | Руками остаётся | Опасность |
|---|---|---|---|---|
| `first40.sh scan` | 10:00, сразу на вулнбоксе | смотрит сервисы/порты/ключи/ssh/диск | — | 🟢 только читает |
| `first40.sh backup` | 10:05 | сейв `orig` всех сервисов + `SHA256SUMS` | `scp` сейвов к себе на ноут | 🟢 |
| `first40.sh verify` | 12:55 и перед любым откатом | сверка sha256 + `tar tzf` — сейвы целы? | — | 🟢 |
| `sudo first40.sh lock` | 10:15, уже добавив свой ключ | выключает вход по паролю в ssh + проверка | `passwd`, `ssh-copy-id`, удалить чужие ключи | 🔴 запрёт снаружи без ключа → проверка во 2-м окне |
| `backup.sh <п> <метка>` | перед каждым патчем | сейв КОДА без данных | придумать метку | 🟢 данные не берёт |
| `restore.sh <арх> <п>` | MUMBLE / сломал патч | откат кода из сейва + пересборка | решение «откатывать?» | 🟡 базу не трогает — это и спасает |
| `redeploy.sh <п> <метка>` | патч от защитника | сейв → build → проверка CACHED/Up → строка отката | смотреть табло 1 раунд (2 мин) | 🟡 сам НЕ откатывает |
| `collect-logs.sh <п>` | защитник просит логи | пакует ps/logs/df/stats в один файл | отдать файл защитнику | 🟢 |
| `healthcheck.sh` | весь бой, на ноуте | сторож: DOWN → звук + готовые команды | реагировать на тревогу | 🟡 MUMBLE/CORRUPT не видит — их лови на табло |

## Чего автомат НЕ делает (специально)
- Не меняет пароли, не копирует/не удаляет ssh-ключи — это руками, ошибка = заперся.
- Не откатывает сам и не трогает базу/данные — откат данных = CORRUPT, старые флаги пропадут.
- Не пишет и не запускает эксплойты против чужих сервисов — это атакующие, не ты.
