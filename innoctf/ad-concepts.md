# ⚔️🛡️ Attack-Defense — как это работает (шпора новичка)

## Раунд (1–2 мин)
чекер кладёт флаг → читает старые (SLA) → команды атакуют → жюри считает.

## Флаг
формат `[A-Z0-9]{31}=`. Живёт 5–10 раундов, потом протухает.

## Вердикты чекера
| | | |
|---|---|---|
| OK ✅ | работает | плюс SLA |
| DOWN 💀 | не отвечает | минус SLA |
| MUMBLE 🗣️ | мусор/падает | минус SLA |
| CORRUPT 🧥❌ | флаг не тот/пропал | минус SLA |

## Очки
атака + защита + SLA. В ForcAD **SLA множит** → упавший сервис убивает счёт.

## Порядок на игре
1. сервис жив (не трогай зря)
2. заплатка (минимально, не ломая чекер)
3. потом атака

## Три «плохих секрета» (где искать дыру)
- 🔢 считается из публичного (`md5(id)`)
- 🔑 простой/предсказуемый (`123`, `id+1`)
- 🚪 пустой/дефолтный (`""`, None)

## Правило патча
меняй МИНИМУМ — одну дырявую строку. Бэкап до, `curl` после.
