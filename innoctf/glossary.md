# 📖 Словарик AD: термины из чата команды (19.11)

Картинка: 🏰 у каждой команды свой **замок** (вулнбокс), в нём **сундуки** (сервисы), в сундуках **флаги**.

## 🏰 Игра
| Слово | По-простому | Картинка |
|---|---|---|
| **А/Д, AD** | Attack-Defense: все атакуют всех и защищают своё | 🏰 война замков |
| **вулнбокс, vulnbox** | сервер, где стоят НАШИ сервисы (выдают орги) | наш замок |
| **сервис** | программа с дырами (сайт, бот), в ней флаги | сундук |
| **флаг** | секретная строка, её крадут и сдают за очки | 🚩 монетка |
| **чекер, чек-система** | робот жюри: кладёт флаг, проверяет, что сервис жив | 🤖 ревизор |
| **SLA** | процент времени, когда наш сервис жив | ❤️ здоровье замка |
| **сабмит** | сдать украденный флаг жюри | 💰 сдать в кассу |
| **сервак** | сервер. В чате ещё и сервер в **Discord** (созвон) | — |

## ⚔️ Атака (не твоё, но знать слова)
| Слово | По-простому |
|---|---|
| **эксплоит, сплоит** | скрипт, который лезет через дыру и достаёт флаг 🗝️ |
| **S4DFarm, фармилка** | ферма: гоняет сплоиты по всем командам и сама сдаёт флаги 🌾 |
| **Neo, раннер** | запускалка сплоитов. Команда сказала «слишком сложно», замена: простой цикл |
| **сканер** | штука, которая ищет, что открыто у соперников |
| **пывн, pwn** | задачи на бинарники (программы на C), а не на сайты |

## 🛡️ Защита (тоже не твоё)
| Слово | По-простому |
|---|---|
| **деф, дефендер** | защитник |
| **патч** | заплатка на дыру в коде 🩹. **Ставишь его ты** (сейв → патч → сторож) |
| **Packmate** | смотрит весь трафик к нам: кто и чем стучит 🔍 |
| **Wireshark** | то же, но общий и неудобный для AD |
| **ctf_proxy, прокси** | охранник у двери сундука: плохие запросы не пускает 🧱 |
| **WAF, фильтр** | то же самое, общее слово |
| **мирроринг** | соперник пересылает наш же трафик в чужой сервис, чтобы спрятать атаку. Запрещено правилами |
| **ДоС, досить** | завалить сервис мусором, чтобы упал. Запрещено |
| **tcpdump** | записать трафик в файл из терминала |

## 🏗️ Инфра (ТВОЁ!)
| Слово | По-простому | Ты это… |
|---|---|---|
| **Docker, контейнер** | сервис живёт в «квартире» 🏠 | ✅ умеешь |
| **образ, image** | чертёж квартиры, из него запускают контейнер | ✅ |
| **.yaml, compose** | файл «какие квартиры поднять и как» | ✅ |
| **docker save / load** | упаковать образы в файл → на флешку → распаковать на месте | ⏳ сегодня |
| **healthcheck, аптайм, мониторинг** | сторож 🔔 | ✅ |
| **бэкап** | сейв перед боссом 💾 | ✅ |
| **SSH** | зайти в терминал вулнбокса со своего ноута | ⏳ Блок 0 |
| **VPN** | «туннель» в сеть игры, без него не видно ни вулнбокс, ни соперников | ❓ спросить на пт |
| **Ansible, playbook** | робот, раскатывающий патчи на много серверов. **Команда выкинула** | ❌ не нужно |
| **sudo** | права админа. На ноутах оргов может не быть | ❓ |
| **хардкод** | IP вписан прямо в код. Плохо: лучше в один файл `.env` / `config` | — |

## 💽 Флешка
| Слово | По-простому |
|---|---|
| **оффлайн** | без интернета: всё надо принести с собой |
| **pip, wheel, .whl** | pip ставит библиотеки Python, `.whl` = библиотека-коробка, её можно принести на флешке |
| **бинарник** | готовая программа, запускается без установки |
| **.deb** | установщик программы для Ubuntu |
| **бубунта, сток** | Ubuntu «как из магазина», без хакерских тулз |
| **Kali** | Linux с кучей хакерских тулз |
| **гипервизор, VirtualBox** | программа, запускающая «компьютер в компьютере» |
| **Flask** | библиотека Python для сайтов. Скорее всего сервисы на нём |
| **llama.cpp** | запустить ИИ-модель без интернета. ⚠️ сначала проверить правила |
| **Obsidian** | блокнот для .md-шпор |
