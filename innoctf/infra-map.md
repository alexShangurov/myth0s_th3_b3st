## 📌 Цифры игры
| Что | Значение | Что это значит для тебя |
|---|---|---|
| Наша сеть | `10.2.X.0/24` (X = номер команды) | |
| **Вулнбокс** | **`10.2.X.2`** | в `services.conf` хост = он, не 127.0.0.1 |
| Шлюз | `10.2.X.1` | **все** атаки приходят с него: кто бьёт, не видно |
| Жюри / табло | `10.10.10.10:80` | вкладка с табло открыта весь день |
| Прокси в интернет | `10.10.10.10:8080`, сертификат `/cert` | только **GET** и белый список сайтов → флешка решает |
| Раунд | **2 мин** | смотреть табло раз в раунд = раз в 2 мин |
| Жизнь флага | **5 раундов = 10 мин** | сервис с нуля = до 10 мин красного ❗ |
| Вулнбокс | Ubuntu 26 server, **живое железо** | оргов не перезагрузить и не перепрошить: сейв = единственное спасение |
| Ноуты | Kali Linux, свои, делаем что хотим | sudo есть |

🧠 **Главный вывод:** «пересоздать сервис с нуля» = потерять старые флаги = **10 минут штрафа**.
Поэтому откатываем **код**, а **данные не трогаем** (как и учили: `backup.sh` их не берёт ✅).

## 🔒 1. 10:00–10:40 · ЗАМОК (сеть закрыта, 40 мин)
🤖 **Автомат `first40.sh`** (на вулнбоксе): `scan` 🔍 смотрит всё → `backup` 💾 сейв всех → `sudo … lock` 🔐 шаги 4–5.
Руками остаются шаги 1–3 (пароль и ключи). Порядок: `scan` → 1 → 2 → 3 → `lock` → `backup` → `scp`.

**«Первым делом» = 🚪 двери.** Чужой с паролем по умолчанию в 10:40 = снесёт всё, оргу не помогут.
| # | Шаг | Команда |
|---|---|---|
| 1 | Сменить пароль на вулнбоксе | `passwd` |
| 2 | Свой ключ | `ssh-copy-id user@10.2.X.2` (ключи всей команды тоже) |
| 3 | Удалить лишние ключи | `nano ~/.ssh/authorized_keys` (и у root: `sudo cat /root/.ssh/authorized_keys`) |
| 4 | Выключить вход по паролю | `PasswordAuthentication no` в `/etc/ssh/sshd_config` **и** в `/etc/ssh/sshd_config.d/*.conf` → `sudo systemctl restart ssh` |
| 5 | ✅ **ПРОВЕРИТЬ** | `sudo sshd -T \| grep -i passwordauth` → `no`; с ноута `ssh -o PubkeyAuthentication=no user@10.2.X.2` → **Permission denied** |

⚠️ Ловушка 4–5: файл в `sshd_config.d/` перебивает главный (так «отключили, а пустило» у команды в прошлом году).
⚠️ Старую SSH-сессию **не закрывать**, пока не зашёл новой по ключу.

**«Вторым делом» = 📦 сундуки.**
| # | Шаг | Команда |
|---|---|---|
| 6 | Найти все сервисы | `docker ps -a` + `sudo ss -tlnp` (часть может быть **не в Docker**, а на хосте: `systemctl list-units --type=service`) |
| 7 | Открытые порты | `sudo ss -tlnp`: база (5432, 3306, 6379, 27017) наружу не нужна → сказать защитникам |
| 8 | Сейв на вулнбоксе | `~/infra/backup.sh <папка> orig` для **каждого** |
| 9 | Сейв к себе | с ноута: `scp -r user@10.2.X.2:<папки> ~/orig/` |
| 10 | Сторож | на ноуте `./healthcheck.sh`, проверить: все ✅ |

⚠️ Пароль базы по умолчанию: менять **только** вместе с конфигом сервиса и `backup.sh` до этого, иначе сервис DOWN.
⚠️ Docker обходит `ufw`: «закрыть порт» = поменять `ports:` на `127.0.0.1:5432:5432` в compose, а не фаервол.

## ⚔️ 2. БОЙ: три ситуации (10:40–13:00 и 14:00–17:00)
**🔔 А. Сторож заорал (DOWN)**
```
логи (сторож печатает) → понял?
   ├─ сломал патч → ⏪ restore.sh <последний.tgz> <папка>     (данные целы)
   ├─ упал сам    → docker compose up -d   (на хосте: systemctl restart <с>)
   └─ ❌ НЕ пересоздавать с нуля и НЕ down -v: 10 мин без флагов
```
**🩹 Б. Патч от защитника** → одной командой: `redeploy.sh <папка> <метка>`
```
redeploy.sh сам: сейв before- → up -d --build → ловит CACHED на COPY 🛋️ → ps → строка отката
Руками: патч вставить ДО запуска; потом ждать 1 раунд (2 мин) и смотреть табло.
Логи для защитника: collect-logs.sh <папка> → один файл в ~/logs/
```
**🟡 В. MUMBLE / CORRUPT на табло** (сторож их не видит!)
- MUMBLE → чаще всего свежий патч → ⏪ откат
- CORRUPT → данные пропали → базу **не трогать**, сказать защитникам

⏱️ Каждые 2 мин: сторож + табло. Каждые ~30 мин: `df -h`.

## ⛔ Пять «НИКОГДА»
| Никогда | Почему |
|---|---|
| `down -v` / пересоздать с нуля | флаги 5 раундов → 10 мин красного |
| откатывать базу | старые флаги пропадут |
| `restart` после патча | вышел-зашёл, код **старый** |
| патч без сейва | нечем откатиться |
| закрыть SSH-сессию до проверки ключа | заперся снаружи, оргам не перезагрузить |
